# ha-milkdrop-renderer

## Pull requests

- Changes go to a `claude/<short-topic>` branch and a pull request. Don't push to `main` directly and don't merge your own PR; Adam reviews and merges. Review feedback goes on the same branch.
- Home Assistant and ESPHome changes are delivered as files in the PR for Adam to apply. The HA connectors are read-only on purpose; don't look for a way around that.
- Every pull request includes a changelog entry in this repo's `CHANGELOG.md`: newest first, in plain language, saying what changed and what to do after merging. If the repo has no changelog yet, the PR starts one.
